Когда начинается новая сессия в claude code ты ориентируешься по файлу @ROADMAP.docx, чтобы понять что сделано, что делаем и как будем делать.

Если какую-то фичу делаем, то заполняем это @ROADMAP.docx

Во время выполнения задачи может какая-то новая фича придти мне в голову и могу тебе написать об этом. Такие идеи, пометки добавь в @ROADMAP.docx

В документе @ROADMAP.docx фичи должны быть сгруппированы. На пример правки по интерфейсу, бэкенду, схема датчиков, электроника, доработки. Если из описанного списка нет категории для фичи, то сам добавляй.
